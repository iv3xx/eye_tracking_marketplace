# Разработка средств оценки информативности и дизайна страниц маркетплейсов с применением технологий распознавания траектории взгляда  
Development of Tools for Evaluating the Informativeness and Design of Marketplace Pages Using Gaze Trajectory Recognition Technologies

Это средства оценки дизайна и привлекательности маркетплейсов с применением отслеживания взгляда, предназначенные для проведения UX-анализа интерфейса сайтов.

Проект был завершен во время подготовки **Анастасией С. Ивановой** дипломной работы бакалавра в Институте компьютерных наук и кибербезопасности СПбПУ (ИКНК СПбПУ).

## 🇬🇧 English Summary

These are tools for evaluating the design and attractiveness of marketplaces using eye-tracking, designed to conduct UX analysis of website interfaces.

The project was completed during **Anastasia S. Ivanova's** bachelor's thesis at the Institute of Computer Science and Cybersecurity at SPbPU (ICSC SPbPU).
